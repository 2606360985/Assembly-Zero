# 当前实现情况（2026-10-13）

项目已经从运输算法演示推进到可持续生产的模块化灰盒工厂，尚未达到最终美术和独立发布验收阶段。

## 已实现

- EP01：Naive 与 Gap 两套整数物流后端、固定 60 Hz Tick、20,000 逻辑物料压力演示、闸门堵塞与恢复、实例化货物显示和性能统计。
- EP02：六轴机械臂、固定连杆与 IK、物料和安装槽预订、产品停站、六类原始身体部件依次安装、扫描、有限下游与出库、暂停/单步/重播和多镜头。
- EP03：三类原料仓储及补货，基础加工、零件制造、六类部件装配、六工位总装与有限成品出库；完整版 45 个功能模块、30 台加工设备、83 条连接，另有最小链场景。
- 配方、缓存、物料身份、所有权交接、批次与成品历史均由纯 C# Domain 决定；表现层读取状态，账本检查贯穿生产、停供和堵塞恢复。
- 布局配置保存设备位置、占地、端口与明确连接；正交路线绕开设备及扩建区，局部桥梁处理跨线，坡度上限 40°，支脚避让下层运输线。
- 模块 Visual 与功能根/接口隔离；提供生成、路径优化、校验、截图和手动冻结菜单。

## 本次皮带模型细化

- 常规平面直角采用专用 Arc Corner90 圆弧模块标记，中心半径最大 0.48 m，16 段弧形网格。相邻短线按长度缩小半径。
- 空间不足、内侧护栏可能翻折的位置采用 Compact Corner90 紧凑转接台，带圆形转接盘，避免强行套用过小圆弧。
- 带床与两侧护栏按连续截面生成，直线、转角和坡道共用接缝顶点，消除逐段盒子拼接造成的端面交叠和缝隙。
- 货物表现与圆弧带床使用相同中心线；原逻辑长度映射到显示路径，保留现有物流速度、容量和生产确定性。
- 完整版与最小版使用独立网格资产，两份场景均通过编辑器生成并保存。后续可用 Tools > Assembly Zero > Refresh EP03 Rounded Conveyor Visuals 刷新。
