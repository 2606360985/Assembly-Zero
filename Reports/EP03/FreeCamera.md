# EP03 自由飞行相机

完整与最小场景均新增独立的自由相机。右上角保留 50% 面板缩放，并增加「自由相机 [G]」按钮。

| 操作 | 功能 |
|---|---|
| `G` / 右上角按钮 | 进入／退出自由相机，隐藏 UI 后 `G` 仍有效 |
| 按住鼠标右键并拖动 | 环视 |
| 按住右键 + `WASD` | 沿视线前后飞行、左右平移 |
| 按住右键 + `Q` / `E` | 向下／向上移动 |
| 按住右键 + `Shift` | 四倍加速 |
| 按住右键 + 滚轮 | 调整飞行速度，范围 0.5–80 m/s |
| 不按右键时滚轮 | 沿视线前后移动 |
| `Esc` | 退出自由相机并释放鼠标 |
| `C` | 返回并切换固定镜头 |
| `H` | 隐藏／恢复全部屏幕 UI |

在 Game 视图中操作。进入时继承当前固定或导演镜头的位置、朝向和视角；固定、导演和自由相机互斥，只有一台相机输出画面。切换到导演镜头时会退出自由飞行。

飞行使用独立于生产时钟的时间步长，暂停生产甚至 `Time.timeScale=0` 时仍可观察。相机不模拟碰撞，可像 Scene 视图一样穿行检查设备。右键在按钮上按下不会捕获鼠标；松开右键、退出、窗口失焦或卸载场景时均恢复鼠标状态。重新聚焦后需要再次按下右键才会继续飞行。

验证记录：[相机交接回归 4/4](FreeCameraEditMode.json)、[EP03 运行及输入回归 9/9](FreeCameraEP03PlayMode.json)。运行检查覆盖两个场景、三种相机切换、UI 隐藏后的 `G` 键、鼠标环视、移动、升降、调速、暂停时飞行、`Esc` 退出及焦点丢失；切换和飞行均不改变生产账本。
