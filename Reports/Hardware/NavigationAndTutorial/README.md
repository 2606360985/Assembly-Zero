- 45°旋转的中间动画、连续累计、完整一圈无漂移及 1×/2×经营速度独立。

- 地图坐标边缘、矿区、采购站、工厂定位；真实指针点击地图时不穿透建造，不改变经营工厂、资金或皮卡任务。
