# 星铸显卡经营切片

打开 `Assets/_AssemblyZero/Scenes/Hardware_Business.unity`，进入 Play。Windows 构建菜单：`Tools > Assembly Zero > Build Hardware Windows Player`。

## 首次游玩
左上角显示当前目标和“下一步”按钮：接单 → 补料 → 生产 → 首款产品下线 → 预留 → 交付。按钮会打开对应页面、预选缺料采购或定位当前工序；采购和交付仍需玩家点击执行。提示根据库存、在途货物和设备状态更新，读取存档后继续。首款产品完成包装时单独提示并记录里程碑。

1. 订单 → 晨湾工作室 → 接单。开局包含六座基础设施和公开赠送的 8 套板材、核心、显存、外壳、包装，以及 2 个标准散热器。
2. 约 4 分钟后第一张合格显卡进入仓库。剩余 6 个散热器可以直接采购，也可以建散热器加工机并采购 12 份铝材。更长期可增加铝材加工机，采集免费铝原料。
3. 采购页切换物料、数量和配送方式。常规 90 秒/12元，加急 25 秒/48元，自提装运费3元；库存每120秒补足。已购货物仓满会保留在途。
4. 首单需要 8 张标准版：订单页预留库存，再整单交付。取消、超期释放预留，不扣罚金。预留成品不可回收或跨厂运输。
5. 首单完成后可接静庭低噪订单。产品页切换到静音产线，采购低噪散热器及6套上游物料。切换等待当前批次完成，必要时在设备页检查待改建状态。
6. 资金不足时可接维修社小额订单，或采铝原料交给有限回收渠道换取加工资金。没有离线收益或隐藏测试注资。

## 操作
- 左键选择/放置，R旋转，右键/中键拖动，滚轮缩放。
- 顶部菜单/Space暂停全部业务；Esc优先取消放置、关闭抽屉，再打开暂停菜单。
- 手动驾驶模块暂时冻结，Tab打开运输页。选择当前目标工厂，点击“规划循环采集铝原料”；也可查看矿点与车库后点击矿点。皮卡自动行驶、采满返厂、卸货并继续采集，无需WASD或E操作。
- “停止任务并返厂卸货”结束循环，货物保留；仓满时车辆等待空间，矿空时等待再生。皮卡采集免费，受全局暂停和1×/2×影响。
- 自提采购会在空闲皮卡可用时自动派遣；忙碌时在运输页点击“自动取回当前厂采购”。分批取回全部待提货物后待命。救援返库需60模拟秒，结束后自动卸货。旧手动驾驶存档载入后自动返厂卸货。
- 管理抽屉不暂停，暂停菜单冻结生产、期限、配送和车辆。
- 手动保存和60秒自动保存到独立 `AssemblyZero-Hardware-v2.json`，损坏时尝试 `.bak`。旧 EP04 v1 存档不会迁移或被新战役覆盖。
- 菜单可打开旧 EP04 入口；两套规则使用同一 Domain 和 Gap 物流实现。

## 经济与成本
静态配置在同目录 `Economy.asset`。全部新经济金额用整数分；旧 EP04 仍使用旧金额约定。Core与Memory独立计料，所有规格均为原创游戏指标。

| 项目 | 标准版 | 静音版 |
|---|---:|---:|
| 外购核心/显存/板材/外壳/包装 | 282元 | 282元 |
| 外购散热器 | 60元 | 100元 |
| 加工费：板卡/总装/检测/包装 | 3/2/1/0.5元 | 3/2.5/1.5/0.5元 |
| 合同单价 | 480元 | 560元 |

基础购料合计为180+60+30+10+2=282元。标准替换成本348.50元、静音389.50元（均未计运费）。赠送库存实际账面成本为0，界面预估使用补货成本，不把首单赠送收益当作长期利润。

标准首单示例：8件收入3840元；赠送材料零成本；另购6个散热器360元；常规配送12元；8件加工52元。实际毛利3416元。现金由3000变为6416元。设备购买是独立现金支出，不混入订单毛利。

每次加工累加输入物料的实际材料、加工、运费成本和本次加工费；运费按件平均分摊，余数按创建ID顺序分配。交付写入独立结算快照，后续价格改变不会重算历史毛利。顶部是最近5分钟模拟时间的现金净流入，不是利润。

## 结构与边界
- `HardwareCatalog`：配置默认值；`WorldSimulation` 的 Hardware partial：订单、采购、驾驶。
- `HardwareGame`：时钟、输入、相机、保存；`HardwareHud`：uGUI/TMP；`HardwareFactoryView`：读取状态的工业表现。
- 物料编号32–47遵循共享后端64位类型掩码，旧0–19不变。
- 仓库声明供应可采购物料、铝原料和成品；板卡/待检显卡/检测后显卡由工序直供。仓库接收最终包装成品，不自动仓库互供。
- 生产节点采用统一的低多边形科技微缩造型，包括倒角机壳、操作屏、圆形机械细节与按实际生产进度驱动的机构。节点位置、端口与输送路线沿用现有规则，EP03左侧输送布局未改动。
- 本轮不模拟晶圆制造、随机良率、员工、燃油、交通AI、自由SKU设计或联网。

实际测试、画面、帧时和未验证项目见项目根 `Reports/Hardware`，不能用旧报告或模拟Tick耗时替代。

## 科技工厂视觉迭代 · 2026-10-23

- 厂房采用后墙、侧墙、前侧低墙和开放装卸口，不遮挡生产线。地坪、设备材质、物流标记及 uGUI/TMP 界面使用统一的石墨、浅灰和青色视觉语言。
- 显式物料视觉表覆盖 16 种物料：PCB 裸板、核心与显存贴装、待检显卡、合格显卡和品牌包装各有独立轮廓。标准版为石墨双风扇，静音版为浅色三风扇与加厚散热。工位不会在加工未完成时显示已入库的合格成品。
- 矿区位于世界网格 `(12,72)`，采购区位于 `(36,64)`；车辆绕开厂房与墙体沿外围道路自动往返。运输页可分别定位矿区、采购站、皮卡与当前工厂。车辆速度未提高，远距离自提和采矿会比旧版耗时更长。
- 皮卡按路径段的 Tick 进度连续显示位置并平滑转向，暂停冻结当前位置。货物按材质复用视图，探索和通知更新不再销毁重建整厂。
- 全部显卡产线复用 EP03 的 16 段圆弧中心线和连续截面扫掠网格：带床、双侧护栏与货物共用路径；短端口、坡道折返采用独立等宽封口截面，垂直交接保留导向框。货物按弧长插值位置和朝向，显示比例适配原有 512 单位间距，仿真长度与吞吐不变。共享扫掠器抽为运行时工具，EP03 既有布局及烘焙网格无需重建。
- 旧 Hardware v2 存档通过独立布局版本执行一次迁移，保留经营与载货数据，更新矿点和受影响路线；旧 EP04 存档及其世界寻路不变。新战役、读取和切换工厂同步刷新表现缓存。
- 直接打开原有 Hardware 场景 Play 即可，不需要重新生成场景。新版原生测试、截图、录像、构建及帧时记录位于 `Reports/Hardware/VisualIteration`。

首单或静音合同取消/超期后，会保留旧记录并生成新报价。重新接单会重新计算期限；已成功完成的固定合同不会无限刷新。
