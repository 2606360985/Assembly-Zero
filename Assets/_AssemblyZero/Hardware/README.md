# 星铸显卡经营切片

打开 `Assets/_AssemblyZero/Scenes/Hardware_Business.unity`，进入 Play。Windows 构建菜单：`Tools > Assembly Zero > Build Hardware Windows Player`（只打包显卡场景）。改动经济配置后运行一次 `Tools > Assembly Zero > Refresh Hardware Economy`；场景和左侧输送区不会被重建。

## 首次游玩
左上角显示当前目标和“下一步”按钮：接单 → 按推荐位放置总装/检测/包装打通产线 → 成品入库自动分配并交付 → 订单板与市场行情开放。新手引导以青色呼吸描边标出下一项导航入口或具体操作；等待到货和生产时不催促重复采购。首单交付后结束新手高亮，订单板继续提供任务提示。

按 H、目标面板按钮或暂停菜单中的“新手引导”开关可随时开启或关闭高亮；选择保存在本机，不改变战役存档。

1. 开局只有仓储、板卡装配和交付站台，赠送 12 套核心/显存/板材/外壳/包装与 4 个标准散热器。接首单（3 张标准版）后按地面青色推荐位放置显卡总装、检测、包装，首张卡约 57 秒下线，首笔收入约 107 秒到账。
2. 订单页是卡片式订单板：显示客户、产品、数量、单价、交期、提前奖金（前60%时间 +15%）、迟交折扣（-25%）、超期作废违约金（10%）与口碑门槛。接单自动锁定库存，成品入库自动分配，配齐即自动交付——没有手动“预留”步骤。
3. 分级结算：提前 +15% 且口碑 +5；准时全额 口碑 +3；迟交 -25% 口碑 -3；超过交期 1.5 倍作废，扣违约金 10% 口碑 -6。口碑档位（无名/新锐/口碑/金牌/传奇）决定订单板出现什么客户。取消在途订单扣 5% 违约金、口碑 -4，脚本合同会重新报价。
4. 首单交付后：良率开启（总装 10%、检测 4% 次品率，设备升级可降低），订单板每 35 秒刷新（最多 5 个，报价寿命 80 秒，同时最多 3 单在途），市场事件开始轮换——挖矿潮、AI 热潮、矿难、芯片紧缺，提前 60 秒在顶栏预告，影响采购价、合同价与现货价。
5. 次品（NG 卡）可以：造返修台（次品+显存→对应规格待检卡）、造丐版包装机（次品+包装→丐版）、或市场页卖给翻新商。丐版也能接电商合同。
6. 采购页切换物料、数量和配送方式；“采购总览”打开全部采购件的库存与缺口弹窗，可筛选缺料、选中物料并直接采购。总览按当前厂已接订单计算，区分本厂现货、在途/待提与供应商库存，扣除成品、半成品及生产批次；有对应加工机时优先折算自制散热器/铝材。缺口按理论用量估算，不预测后续采矿或额外良率损耗，补料货款估算不含运费。价格随市场事件浮动（市场页有行情表）。常规 90 秒/12元，加急 25 秒/48元，自提装运费3元；库存每120秒补足。
7. 资金归零也能翻盘：采矿卖现货（成交额度 50 件/5分钟），再接维修社小额订单恢复生产。没有离线收益或隐藏测试注资。

## 操作
- 底部固定 7 个常用设备槽位，1–7 快捷放置；拖动槽位交换位置，右键槽位从设备库替换。快捷栏独立保存在本机界面偏好中，读档、新战役和新增品类不会自动重排有效槽位。
- “全部设备”向上展开分类、搜索和卡片网格；点击设备进入放置，拖入常用槽位或点击“固定到快捷栏”后选择槽位。点击已有设备，详情顶部可升级、移动或进入返修相关操作；返修台仍按配方自动生产。
- 左键选择/放置，R旋转设备；WASD沿当前画面方向移动视角，右键/中键拖动，滚轮缩放。
- Q/E 围绕画面中心地面点旋转45°；顶部速度按钮在 1×/2×/4×/8× 间循环，空格或顶部菜单暂停。
- 设备头顶显示利用率条与状态灯（绿=运行、黄=缺料、红=堵塞、紫=资金不足、灰=未连通）；瓶颈设备标红并带【瓶颈】标签；积压的输送带会变暗红。
- 左下角小地图显示全局工厂、已发现矿区、采购站、道路、皮卡与当前视野；点击地图快速定位。
- 手动驾驶模块暂时冻结，Tab打开运输页。皮卡自动行驶、采满返厂、卸货并继续采集。
- 管理抽屉不暂停，暂停菜单冻结生产、期限、配送和车辆。
- 手动保存和60秒自动保存到 `AssemblyZero-Hardware-v3.json`，损坏时尝试 `.bak`。v2 旧存档与新规则不兼容，不会被读取或覆盖。

## 结构与边界
- `HardwareCatalog`：配置默认值与内容版本；`WorldSimulation` 的 Hardware partial 分文件实现：`HardwareEconomy`（订单/结算/采购/现货）、`HardwareOrders`（订单生成器）、`HardwareMarket`（事件状态机）。
- `HardwareGame`：时钟、输入、相机、保存；`HardwareHud`：uGUI/TMP；`HardwareFactoryView`：读取状态的工业表现。Unity 表现层不持有货物、现金或生产状态。
- 物料编号32–49遵循共享后端64位类型掩码，旧0–19不变；48=次品、49=丐版。
- 仓库声明供应可采购物料、铝原料、次品和成品；工序中间品直供下游。
- 节点位置、端口与输送路线沿用现有规则，EP03左侧输送布局未改动。
- 本轮不模拟晶圆制造、员工、燃油、交通AI、自由SKU设计或联网；产品设计师/科技树/竞争厂商在后续里程碑。

实际测试、画面、帧时和未验证项目见项目根 `Reports/Hardware`，不能用旧报告或模拟Tick耗时替代。
