# EP04 工厂经营原型

打开 `Assets/_AssemblyZero/Scenes/EP04_Business.unity` 后 Play。沿用 Unity 6000.4.0f1，不需要重新生成 EP03。

## 从第一台设备开始

1. 左侧选择仓库，在厂地点击放置；再放制造机和销售站。首座仓库和销售站免费，制造机 180。
2. 端口之间自动铺设正交输送线。默认制造工业零件包，销售站以每件 25 收购。可先建下游，缺料时设备等待。
3. Tab 打开世界地图。点击资源标记，再点“采集至当前厂”；点击空地让皮卡探索，发现塑料、电子原料及第二厂址。
4. 首次出售 T1 后可升级 L2 设备、雇采集队；另建制造机并切换配方生产驱动组件。加工机可生产塑料壳、电路板。
5. 出售 T2 后可升级 L3 制造机生产作业机器人。销售 T3 后，发现并购买第二厂址。两厂各自放仓库、生产机和销售站，通过皮卡或运输队调拨物资。

## 操作

- 点击节点查看状态；R 旋转放置预览，Esc 取消；移动设备免费，拆除返还累计投入的 75%。
- Space 暂停，顶部切换 1×/2×；车辆加速仅影响选中车辆的行驶。
- 物流面板可逐物料设置供应方、接收优先级和销售前保留量。加工需求优先于销售，同级接收轮询。
- 配方切换、拆除等待当前批次完成。正在加工的节点可以移动，保留进度。改建回收物料需要仓库空间；失败不会扣款或丢货。
- 原料是金属、塑料、电子原料；T1/T2/T3 固定售价为 25/90/220。L1/L2/L3 速度为 1/1.5/2，升级费用 300/650。
- 仓库总容量为 300×等级；正常入库每种物料上限为总容量的 25%，其余空间可用于改建回收。车满或仓满会实际等待。
- 皮卡免费使用，采集队/运输队价格 450/600，每趟费用 8。资金不足时停止派遣；已有货物保留。
- 采集站 250，提高采集速度。第二厂址 22000。数值在 `Economy.asset` 集中配置。
- 手动保存及每 60 秒自动保存。点击“继续”加载存档；主文件损坏时尝试上一份备份。新游戏需再次点击确认。无离线收益。

## 架构与边界

`WorldSimulation` 是无 Unity 引用的固定 Tick 领域模型。所有经济与建造命令在 Tick 边界提交。新经营模拟不依赖 EP02 总装；旧 EP03 的配置和场景保持原样。

自动连接先决定供需关系，再执行带转弯代价的三层正交寻路。既有有效路线保持稳定，仅重建受影响连接；跨线以桥面/垂直模块区分高度。不同工厂间只允许车辆运输。

物品使用全局唯一 ID 并保留 Origin 工厂；加工、销售、车辆和运输线只能持有同一物品的一个归属。有限明细日志不保存无限历史。Gap 后端的保存接口输出规范化距离、顺序和计数器，恢复后继续同一 Tick。

独立构建菜单：`Tools > Assembly Zero > Build EP04 Windows Player`。构建期间使用当前已安装 URP 包创建的 EP04 全局设置，结束时恢复旧项目的设置引用；不通过修改旧资产版本号绕过检查。

首版使用体块、固定地图、地图指令车辆。没有人物、手动驾驶、战斗、燃油、随机地图或联网。容量压力测试是独立合成负载，不等同于实际关卡帧率。
